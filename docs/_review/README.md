# Internal review record — not published

`_review/` held the per-iteration and stage-boundary audit outputs: security
reviews, pentests, performance passes, and the append-only gate ledger
(`evaluations.jsonl`) that recorded which rungs cleared which gate.

It is maintained in Brainstorm's private repository. These are internal audit
artefacts — they catalogue where this codebase has been weak and how those
weaknesses were found. The findings themselves are fixed and the fixes are in
the public history; the audit narratives are not.

Published docs that cite a specific audit name it in prose rather than linking
to it.
