# Twitter / X — Brainstorm 0.9.0 release

hero (Agent-11). Pairs with the reel in `vid-agent-team.md`; drop the reel on

## Thread version

### Tweet 1

Brainstorm 0.9.0 is out — Mac, Windows & Linux 🎉

We call this one "Work with the agent."

The AI doesn't just chat. It drafts real objects into your vault — a contact, a task, an event, a note — and you approve what you keep. A teammate, not a prompt box.

[video: the propose → approve reel]

### Tweet 2

The important part: the agent *can't* write to your vault.

It proposes. You commit.

Even a hidden instruction buried in a document can only ever draft a card — never save one. The approve button is yours. And it all runs on your machine.

### Tweet 3

How it feels in practice:

"Just got off a call with a lead — set me up to follow through."

→ it drafts a contact, a follow-up task, a check-in
→ you fix a field right on the card
→ approve the ones you want, drop the rest

They land in Contacts, Tasks, Calendar — real, yours.
